# Saso AI Resume Builder

أداة مجانية لإنشاء سيرة ذاتية (CV) احترافية بالذكاء الاصطناعي. اكتب بياناتك واحصل على سيرة ذاتية جاهزة في دقائق.

**جرّب التطبيق:** https://saso-ai-resume-builder.streamlit.app/

## المميزات
- إنشاء سيرة ذاتية بالذكاء الاصطناعي
- يدعم العربية والإنجليزية
- مجاني وبدون تسجيل

## التقنيات
Python, Streamlit
